Политика конфиденциальности игры «Кроха-Ракета»

Дата вступления в силу: 12.10.2026 · Редакция 1.6

1. Какие данные обрабатывает игра

  • Игровой прогресс (уровни, звёзды, коллекция, настройки звука/языка, счётчики) — хранится локально в браузерах/устройствах игрока и, при игре через платформы (VK, GamePush), в облачном сохранении платформы по ключу save. Синхронизация выполняется только при входе игрока в аккаунт платформы.
  • Язык интерфейса — определяется из настроек платформы/браузера, не передаётся третьим лицам.
  • Технические события (факт показа рекламы, факт награды за рекламу) обрабатываются SDK платформы (VK Bridge / GamePush) внутри их контура согласно их политикам.

2. Чего игра НЕ делает

  • Не собирает персональные данные (имя, e-mail, телефон, геолокацию, контакты).
  • Не использует сторонние трекеры, пиксели и аналитические скрипы вне SDK платформы.
  • Не передаёт данные рекламодателям напрямую: рекламу показывают SDK платформ (VK / GamePush) в рамках их политик.
  • Не требует регистрации: весь прогресс доступен гостем.

3. Хранение и удаление

  • Локально: localStorage браузера; удаляется кнопкой «Настройки → Сбросить прогресс» или очисткой данных сайта.
  • Облако платформы: удаляется согласно правилам платформы (VK / GamePush) по запросу игрока в поддержку платформы.

4. Дети

Игра семейная (0+), не направлена на сбор данных детей и не содержит чатов и социальных функций.

Privacy Policy of the game “Tiny Rocket”

1. Data the game processes

  • Game progress (levels, stars, collection, sound/language settings, counters) is stored locally on the player's device and, when played via a platform (VK, GamePush), in the platform's cloud save under the key save. Sync happens only through the player's platform account.
  • Interface language is read from platform/browser settings and is not shared with third parties.
  • Technical events (ad shown, reward granted) are processed by the platform SDK (VK Bridge / GamePush) inside their perimeter under their own policies.

2. What the game does NOT do

  • It does not collect personal data (name, e-mail, phone, geolocation, contacts).
  • It does not use third-party trackers, pixels or analytics outside platform SDKs.
  • It does not pass data to advertisers directly: ads are served by platform SDKs (VK / GamePush).
  • It requires no registration: full progress is available as a guest.

3. Storage & deletion

  • Local: browser localStorage; removed via “Settings → Reset progress” or site-data clearing.
  • Platform cloud: removed per platform (VK / GamePush) rules upon the player's request.

4. Children

The game is family-friendly (0+), does not target children's data and contains no chats or social features.
